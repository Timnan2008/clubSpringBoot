# 注册验证

React 注册表单仍使用 Cloudflare Turnstile。一次性 token 在 `/api/user/registration-verification` 由服务端 Siteverify 验证；成功后在当前 HTTP 会话内保留五分钟的注册凭据，绑定规范化邮箱和身份。凭据不包含原始 token，也不由前端决定是否有效。

`/api/user/add/user` 和 `/api/user/add/teacher` 都检查该凭据。填写错误的邮箱验证码或存储失败后，可以在有效期内修正并提交；完成注册立即移除凭据。更换邮箱、身份、浏览器或者凭据到期，必须重新通过验证。旧客户端直接提交新 Turnstile token 的流程仍兼容。

关键文件：

- `frontend/auth.jsx`：分步表单、验证和重试状态。
- `frontend/Turnstile.jsx`：加载官方 SDK、到期回调和失败重试。
- `config/RegistrationVerification.java`：会话范围、邮箱和身份校验、期限及消费。
- `service/Suggestion/TurnstileService.java`：验证 success、action 和部署域名。
- `config/RegistrationProof.java`：独立的邮箱验证码凭据。

本地回归覆盖凭据重用、过期、跨邮箱/身份/会话拒绝、失败不生成凭据，以及注册失败后重试不重新挂载控件。真实 Cloudflare 自动浏览器验证未取得 token，因此仍需在正常浏览器中检查一次真实注册；测试不会绕过挑战或向真实邮箱发送测试邮件。
