# Agent Ollie 维护说明

## 请求路径

`frontend/OpenClawPage.jsx` 发送当前分支上下文 → `OpenClawController` 校验登录、写入令牌和历史清空标记 → `OpenClawAgent` 组织模型与工具循环 → `OpenClawGateway` 请求模型服务。

`OpenClawTools` 是工具入口；社团权限通过 `WorkspaceAccess` 再次校验。客户端的角色、社团 ID 或聊天 ID 均不能替代服务端授权。

## 联网研究与执行状态

- `OpenClawWebSearch` 返回搜索摘要；`OpenClawWebPage` 提取公开 HTML、文本、JSON 或 PDF 正文。
- 只拿到摘要，或页面依赖脚本/登录且没有正文时，不能声称已阅读全文。
- `OpenClawResearchBudget` 的状态仅存在于单次回答：相同请求复用结果、同一主机两次正文失败后停止猜路径、最多 24 次新联网调用和 10 轮联网工具。240 秒后不再开始新的联网调用；正在生成的模型响应不属于硬实时期限。
- 达到联网上限后要求模型基于已有证据作答；校园工具额度独立。即使提供商继续请求已移除的联网工具，也会终止这一重试循环。
- 第三方路由商价格必须标注来源、提供商、计价单位和日期，不能称为官方直连定价。
- `frontend/openclaw-progress.mjs` 负责 UI 状态归并。只有相同工具、相同参数成功重试才算恢复。已经使用其他正文来源完成回答时，先前不可读的网页标记为中性提示，不伪装成成功读取。

## 记录、隔离与清理

`OpenClawIdentity` 将账号类型和数字 ID 组合成独立身份；不能仅凭旧数字 ID 判断记录所属人。`OpenClawHistory` 保存压缩后经 AES-GCM 加密的历史；其密钥属于私有运行配置。此方案是服务器端加密，持有服务器和密钥权限的管理员仍可能解密，不能称为端到端加密。

清空历史时更新 `resetAt` 标记，旧浏览器的历史写回及旧上下文请求返回 409，刷新后清空本地缓存。清理操作必须核对角色和唯一账号，同时处理有明确归属的网关会话及备份。保留计费汇总，不读取或删除其他账户聊天内容。

不要把环境文件、密钥、日志、数据库业务数据、聊天内容或附件提交 Git。`data/`、`uploads/`、`.env*`、`*.key`、`*.pem` 已被忽略。

## 验证

```sh
npm ci
npm run format:check
npm run build
npm run test:frontend
./mvnw -Dtest='OpenClaw*Test' test
node frontend/tests/openclaw-regenerate.browser.mjs
```

浏览器回归使用本地模拟接口，不能代替生产账号授权检查。上线需核对 JAR SHA-256、服务运行、HTTPS 和发布资源内容；保留可回退 JAR，但恢复代码不得恢复用户已经要求删除的聊天。

- 单次回答的通用工具预算为 128 次执行、48 轮；计划更新不占执行次数。思考内容按句/行输出，过滤已提供的技能说明、资料摘录和附件原文，并隐藏 Markdown 代码块。
- 待办按稳定 id 逐项更新，已完成项保留划线；停止回复将剩余项标记取消，等待审批时暂停运行标记。重编辑重发在实际发送时读取当前模型与深度思考设置。
