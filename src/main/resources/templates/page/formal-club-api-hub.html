Architecture

从浏览器请求到数据库的一条完整链路

Request Flow

Browser ↓ Nginx / HTTPS ↓ Spring Boot Controller ↓ AuthFilter → Service ↓ Repository / JPA ↓ MySQL / Redis

Core Responsibilities

  • Controller：定义 API 与页面路由
  • Service：处理业务规则、事务和权限
  • Repository：负责数据库访问
  • DTO / VO：隔离输入数据与页面展示数据
  • Advice：统一处理模型注入与异常
