# OpenClaw 助手

入口为主站 `/page/openclaw`，顶部复用校园墙导航。只有有效登录的社长、副社长、老师和管理员可以访问；每次 API 请求均重新检查身份。社团工具还会逐次检查该账号对指定社团的权限，社团资料写入、发布、审核和记忆变更经页面确认后执行；生成下载文件直接执行，删除已生成文件由用户手动确认。

页面提供对话历史、流式回复、推理开关、模型选择、上传文件、语音输入、工具运行记录和任务进度。新对话使用 Ballpit 背景和 TextType 欢迎语，第一条消息发送时各个球错开重力下落。输入框按内容增长至视口高度上限，长文本仍可在输入区滚动，但不显示独立滚动条。

Agent 会话、历史、记忆、额度、审批及生成文件使用账号类型与账号 ID 组成的独立键。社团资料仍由有权限的成员共享：Agent 读取资料后必须带回版本号，写入时在数据库行锁内比较版本；若另一位成员先改了资料，写入返回冲突，须重新读取并取得新的确认。回溯资料修改也执行相同校验。同名社团文档不会由 Agent 自动覆盖。旧版只按数字 ID 保存的数据若对应多个账号，不能推断归属，必须留在备份中人工核对。

后端通过 `CLUB_OPENCLAW_URL` 和 `CLUB_OPENCLAW_TOKEN` 连接模型网关。未配置时页面显示「未接入」，不会伪造回答。校园工具涵盖社团资料、社员、申请、文档读取与保存、日历、校园帖、校内检索、公开网页检索与文件准备。当前 `mcp-school` 是本应用提供的校园工具组；外部 MCP 服务尚无端点配置，不能在页面里声称已接入。技能条目是提供给模型的任务指引，不会自动执行未提供的外部能力。联网检索由服务端请求公开搜索结果，返回可引用的标题、链接和摘要；不能保证所有网页都可索引。

本地构建与验证：

```sh
npm run build
npm run test:openclaw
./mvnw -Dtest='OpenClaw*Test' test
```

`npm run preview:openclaw` 在 `127.0.0.1:8091` 提供仅用于界面审阅的本地示例账号，不连接生产 API。它无法证明真实登录、模型输出或校园写入可用。React Bits Pro 付费区块未安装；页面按用户提供的组件源码及参考图自行适配。

详细后端流程、当前额度与停用时间见 [Agent 维护说明](../docs/Agent维护.md)。
